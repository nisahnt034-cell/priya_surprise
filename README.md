## 🛠️ How to Open & Run

1. **Directly in Browser:**
   - Simply double-click [`index.html`](file:///C:/Users/pande/.gemini/antigravity/scratch/priya-birthday-surprise/index.html) to open in Chrome, Edge, Safari, or Firefox.
   
2. **With Local Server (Recommended for Best Audio Experience):**
   ```bash
   cd C:\Users\pande\.gemini\antigravity\scratch\priya-birthday-surprise
   npx serve .
   # OR
   python -m http.server 8000
   ```
   Then open `http://localhost:8000` or `http://localhost:3000`.

3. **Music Toggle:**
   - Click the top-right **Music** button with animated equalizer waves anytime to toggle sound on/off.
   - Any tap or click anywhere on the screen also spawns magical star and heart sparkles!
